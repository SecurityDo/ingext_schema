Behavior rules triggered by events

_behaviors holds a list of behavior rules that one event triggered.

Office365
    | where timestamp > ago(1d)
    | where isnotempty(_behaviors)
    | mv-expand _behaviors
    | summarize BehaviorCount = count() by Behaviors = _behaviors
    | order by BehaviorCount desc
Output
BehaviorsBehaviorCount
O365_AzureAD_UserLoggedIn36

Event counts by GeoIP country

_ip holds the geoIP information (if available).

Office365
    | where timestamp > ago(1d)
    | where isnotempty(_ip.country)
    | summarize Events = count() by Country = _ip.country
